## The resolved parameter is invisible to the model

`terminate_process` takes an `approval` parameter resolved by elicitation.
Its published input schema is:
```json
["pid"]
```

`approval` is absent, so a model cannot forge its own approval.

## Resource template variables are untrusted

- `system://disk/etc` -> MCPError: Unknown disk 'etc'. Known disks: root.
- `system://disk/../../etc/passwd` -> MCPError: Unknown resource: system://disk/../../etc/passwd

## The elicitation question is derived from the arguments only

- asked 1 time(s)
- text: `Terminate process 4242 (unknown)? This cannot be undone.`

The SDK matches a recorded answer against a digest of this exact string.
A question containing a timestamp or a live reading would never match,
and the call would never converge.
